# 📊 Análise Exploratória de Dados Financeiros — 2024

Projeto de análise exploratória (EDA) de dados financeiros mensais utilizando **Python** e **Pandas**, com visualizações geradas com **Matplotlib**.

> Desenvolvido por [Ingridy Isabelli](https://linkedin.com/in/isapinho) como parte do portfólio de dados.

---

## 🎯 Objetivo

Analisar a evolução financeira de uma empresa ao longo de 2024, identificando tendências de receita, composição de despesas, margem de lucro e insights para tomada de decisão.

---

## 💡 Principais Insights (2024)

- 📈 Crescimento de receita de **+124%** de janeiro a dezembro
- 💰 **RH** representa a maior fatia das despesas (~28%)
- 🎯 **Q4 (out–dez)** foi o trimestre mais lucrativo do ano
- 📊 Margem de lucro cresceu de **~18%** (jan) para **~32%** (dez)
